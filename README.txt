SMARTPLAY ARENA — INSTALLABLE PWA
Includes 5 free games: Reaction Rush, Number Hunt, Memory Match, Tic-Tac-Toe, Tap Target.
English/Hindi toggle. Offline caching via service worker.

PUBLISH FREE:
1. Create a GitHub account and a public repository.
2. Upload every file in this folder to the repository root.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Open the published HTTPS URL on your phone.

ANDROID: Open the website in Chrome and use Install app / Add to Home screen.
iPHONE: Open the HTTPS website in Safari → Share → Add to Home Screen.
Browser support and install wording can vary.

STORE FEES:
Google Play Console currently charges a one-time US$25 developer registration fee for full distribution. Apple App Store distribution requires Apple Developer Program membership at US$99/year. Store review and policy requirements also apply. A PWA can be installed directly without being listed in those stores.
